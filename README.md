# IT202 Week 12 – AJAX Assignment

## About This Assignment

For this week's assignment, I created a dog breed search page using HTML, JavaScript, AJAX, and PHP.

The page lets users type in a dog breed and shows suggestions while they are typing. I used PHP to check the breed names and JavaScript to update the results without refreshing the page.

## What I Did

- Created an HTML page with a dog breed search box.
- Added JavaScript and AJAX to display suggestions as the user types.
- Created a PHP file with six dog breeds.
- Uploaded my files to the NJIT AFS server.
- Tested the website to make sure the search feature works.

## Files

- `index.html` – Contains the search box and AJAX functionality.
- `check_breed.php` – Checks the dog breed names and returns matching results.
